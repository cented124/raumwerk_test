# Dein London-Frontend importieren

Du musst keine Dateien von Hand kopieren und nichts programmieren.

1. **Aktuelles [Raumwerk für Windows](https://github.com/cented124/immo_project/releases/latest) verwenden.** Für den vollständigen ZIP-Import wird die neue Version benötigt. [Update mit deinen vorhandenen Daten](https://github.com/cented124/immo_project/blob/main/docs/FRONTEND-IMPORT.md).
2. **[RAUMWERK-IMPORT.zip herunterladen](https://github.com/cented124/raumwerk_test/raw/refs/heads/main/RAUMWERK-IMPORT.zip)** – nicht entpacken.
3. In Raumwerk: **Frontend-Studio → Frontend importieren → ZIP auswählen**. Die Prüfung läuft automatisch.
4. **Als Entwurf übernehmen → Vorschau öffnen → Veröffentlichen**.

Das ZIP enthält die London-Gestaltung, Illustration, eigenen Code und lokale Schriften. Deine Firmenangaben, Immobilien, Anfragen und Zugangsdaten bleiben aus dem Baukasten erhalten. Das Design ersetzt Titel- und Beratungsbild.

**Nicht das einzelne manifest.json und nicht „Code → Download ZIP“ verwenden.** Das alte Manifest übernimmt nur Theme-Werte. Das komplette Repository enthält zusätzlich Entwicklerquellen und ist kein Importpaket.

Für Änderungen am Code: [Entwicklerhinweise](ENTWICKLUNG.md). Für den normalen Import reichen die vier Schritte oben.
